# UDS-TV 편성 거버넌스 규칙 (Scheduling Governance)

> U+tv 홈/전용관 지면을 **표준 모듈**로 편성하기 위한 규칙서.
> 근거: 모듈정의서(Figma page 1:3, 편성 거버넌스 모듈 Spec 2405) 47개 모듈 정의 + 홈 구조.
> 이 문서는 (1) 기획·운영의 편성 기준이자 (2) 화면 생성기(플러그인)가 전용관을 자동 조립하는 데이터 근거다.
> 전용관별 실제 모듈 조합은 `UDS-TV_전용관_편성템플릿.json` 참조.

## 1. 화면 골격 (모든 전용관 공통)

1920×1080. 스크롤형 세로 지면.

| 영역 | 위치 | 비고 |
|---|---|---|
| **전면배너 (J-2)** | 최상단, 풀폭(1920) | 전용관 1st 순서 고정. 하단 포스터(R타입)+배너BG |
| **상단 OTT 숏컷** | (136, 58), 1734×68 | 배너 위 오버레이. 홈 계열만 |
| **좌측 LNB** | (0, 0), 120×1080 | 스크롤 시 콘텐츠 위 오버레이 고정 |
| **콘텐츠 모듈 스택** | x=**136** 시작, 폭 1648 | 세로로 모듈 이어붙임. 다음 카드 peek |

- 모듈 시작 x=136(콘텐츠 영역 1648 = 136~1784), LNB(120폭)와 겹치지 않게.
- 전면배너 단독 사용 시 LNB·OTT는 빠지고, 홈 틀에서만 얹는다.

## 3. 동작 규칙

### 3.1 자동 롤링 (전면배너 J-2)
- 배너 **최대 78개** (리모컨 좌/우 이동).
- 롤링: 상단숏컷 Focus 4초 / 하단 포스터 Focus 4초. UI스크립트에서 포커스 위치별 설정, **0초=롤링 해제**.
- 배너 PIP: MIMS에서 배너별 Y/N.

### 3.2 Focus 후 자동 재생/미리보기 (PIP) 시간표
| 모듈 | 대기 | 동작 |
|---|---|---|
| A-3 / B-3 실시간 | 2초 | 해당 채널 자동재생 |
| K-2 상세 | 2초 | 예고편/미리보기 |
| K-3/4/5/6 상세 | 3초 | 예고편/미리보기 |
| D-5/D-6 프로모션 | 3초 | 예고편/미리보기 |

### 3.3 포커스 표현 (Foundation 준수)
- 글로우 금지. **105% 확대 + 두꺼운 흰 보더(4px, inside)**. 랭킹 숫자는 검정 60% 스트로크로 포스터 위 가독 확보.

### 3.4 갱신 주기
- G-2 인물 랭킹: **1시간** ("HH시 기준" 표기).

## 4. 조건부 노출 규칙
- **이어보기(I-1/I-3)**: 이어보기(또는 애니 이어보기) 콘텐츠 없으면 **모듈 비노출**. 성인 장르 비노출.
- **찜목록(A-12)**: 찜한 콘텐츠 있을 때만 노출.
- **I-2**: 이어보기 4개 미만 & 수동편성 콘텐츠 편성 시에만 노출.
- **미가입자 프로모션(D-1/D-3)**: 나의구독 패널에서 하위지면으로 특정 월정액 미가입자에게만 노출.
- **로그인/고객유형(C-5)**: 로그인 여부 등 고객 유형에 따라 형상 다름.

## 7. Do / Don't
**Do**
- 전면배너는 전용관 1st 순서 고정.
- 모듈은 우리 표준 컴포넌트 인스턴스로만 조립(새로 그리지 않음).
- 콘텐츠 유형에 맞는 이동경로 준수(VOD→상세, OTT→딥링크, 실시간→채널).
- 조건부 모듈은 노출 조건 확인(빈 이어보기/찜 비노출).

**Don't**
- 화면 밖 이탈·핵심요소 Safe Area(50/18) 밖 금지.
- 입력에 없는 취소/되돌리기 버튼 임의 추가 금지(리모컨 '뒤로'가 취소).
- 성인 콘텐츠를 이어보기/추천에 노출 금지.
- 같은 성격 모듈 과다 중복 편성 지양.
